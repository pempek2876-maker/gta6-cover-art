Vice Cover Studio v2 — an offline browser app that turns any photo and caption into GTA 6-style cover art: a layered hero composition (procedural Vice City scene, diagonal photo panels, car and palm silhouettes), big gradient display type with a "VI" lockup, three colour grades (Sunset, Neon Night, Pastel Dawn) with per-panel control, photo treatments (duotone, grain, vignette, halftone), and one-click export of all four common post sizes (1:1, 4:5, 9:16, 16:9) as PNG. No Rockstar logos, artwork or fonts; everything is original, and photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a preset, drop in photos, drag to pan, scroll to zoom, and export.
